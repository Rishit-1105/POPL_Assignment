# S1 prompts

```text
Using #lang racket/base in Racket 8.x, implement only\
a recursive helper function (my-inorder tree) that\
returns a list containing the values of a binary tree\
in inorder (left, root, right).\
\
A tree is either '() or a three-element list\
(value left right).\
\
Use only the built-ins permitted in the assignment.\
Do not use append, reverse, map, set!, or other\
forbidden operations.\
\
Do not implement any other traversal or printing\
function. Explain the recursion briefly.
```

```text
Implement only (print-inorder tree) using the\
previously implemented my-inorder helper.\
\
It must print the inorder traversal as a Scheme\
list using display and finish with newline.\
\
For an empty tree, it must print ().\
\
Do not add top-level calls or implement other tasks.\
Follow the assignment's allowed built-ins.
```

```text
Implement only a recursive function (my-preorder tree)\
in #lang racket/base.\
\
It must return the values of a binary tree in\
preorder (root, left, right).\
\
Use only allowed built-ins and do not use append\
or built-in list traversal functions.\
\
Preserve left-to-right traversal order.\
Do not modify previously implemented functions.
```

```text
Implement only a recursive function\
(my-postorder tree) in #lang racket/base.\
\
It must return the values in postorder\
(left, right, root).\
\
Handle the empty tree, leaf nodes, and trees\
with only one child.\
\
Use only the assignment's permitted built-ins.\
Do not use append, reverse, map, or mutation.\
Do not change existing functions.
```

```text
Implement only (print-all-traversals tree) using\
the existing my-inorder, my-preorder, and\
my-postorder helpers.\
\
Print exactly three lines in this order:\
inorder, preorder, postorder.\
\
Each line must use display to print a Scheme\
list, followed by newline.\
\
Do not print labels, prompts, or extra text.\
Do not add top-level function calls.
```

```text
Implement only (my-height tree) in #lang racket/base\
to return the height of a binary tree.\
\
The empty tree has height 0.\
\
A nonempty tree has height 1 plus the maximum\
height of its left and right subtrees.\
\
Use recursion and only the assignment's allowed\
built-ins.\
\
Do not implement leaf counting or output functions.
```

```text
Implement only (my-leaf-count tree) in\
\#lang racket/base.\
\
A leaf is a node whose left and right\
subtrees are both empty.\
\
The empty tree has zero leaves.\
\
For non-leaf nodes, recursively sum the leaves\
in the left and right subtrees.\
\
Use only the allowed built-ins.\
Do not modify existing functions or implement printing.
```

```text
Implement only (print-height-and-leaves tree)\
using the previously defined my-height and\
my-leaf-count helpers.\
\
Print a single Scheme list containing\
(height leaf-count), using display followed\
by newline.\
\
For the empty tree, the output must be (0 0).\
\
Do not print explanatory text or introduce\
top-level calls.
```

```text
Create only a separate test file for S1's three\
public functions.\
\
Include the assignment's t1, t2, t3, and empty-tree\
examples, plus extra edge cases for a single-node\
tree, left-skewed tree, right-skewed tree, unbalanced\
tree, and repeated values.\
\
Verify exact output order, parentheses, spaces,\
and newline counts.\
\
Keep all test calls out of id_q3.rkt, since the\
grader adds its own calls.
```

```text
Review only the completed S1 file id_q3.rkt\
against the assignment specification.\
\
Check that it starts with #lang racket/base,\
defines all three required public functions\
with exact names, uses only permitted built-ins,\
handles empty trees, prints the correct number\
of lines with newlines, and has no top-level\
calls or output.\
\
Identify any violations and suggest minimal\
fixes without rewriting the entire solution.
```
