# P1: Department Assignment Puzzle (Prolog)

**Tool:** Google Antigravity | **Branch:** Rishit | **Solution file:** code/75_q1.pl

## Approach
I split P1 into small steps, one prompt per unit of work, as the decomposition rule requires. The idea is generate-and-test. One predicate generates every possible assignment of departments, languages and projects, and each clue is a separate clause that filters those assignments. main/0 prints the first assignment that passes clues 1-8. count_solutions/2 counts how many assignments pass a chosen set of clues, which shows whether the puzzle has a unique answer. Clue 9 was added to make the answer unique. Each prompt ended with a commit and push to my branch, so the history shows the work step by step.
