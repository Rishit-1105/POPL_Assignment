# Problem 1 (P1) Report: Department Assignment Puzzle, Reloaded

## 1. Solution Count for Clues 1 to 8 (P1.b)

When running the query:
```prolog
?- count_solutions([1, 2, 3, 4, 5, 6, 7, 8], N).
N = 3.
```

The total candidate space generated by `candidate/1` through permutations of the four departments, languages, and projects is:
$$4! \times 4! \times 4! = 24 \times 24 \times 24 = 13,824 \text{ candidate assignments}$$

Evaluating clues 1 through 8 over all candidates reduces the space to exactly **$N = 3$ solutions**.

---

## 2. Analysis: What $N = 3$ Tells Us About the Puzzle

A well-posed logic grid puzzle should uniquely determine a single assignment ($N = 1$). A value of $N = 3$ indicates that the original 8 clues leave the puzzle **under-constrained**:

1. **Fixed Attributes**:
   - Ben's attributes are completely determined across all 3 solutions:
     $$\text{Ben} = [\text{development}, \text{javascript}, \text{web}]$$
2. **Under-Constrained Attributes**:
   - The remaining three friends (Alex, Carla, and Dana) share overlapping valid assignments across the remaining departments (`design`, `research`, `testing`), languages (`java`, `'c++'`, `python`), and projects (`'AI'`, `data`, `embedded`).
   - Specifically, the association between `java` and project preferences (`'AI'` vs `embedded`) is not fixed by clues 1 to 8.

## 4. Puzzle Repair: Adding Clue 9 (P1.c)

To make the puzzle uniquely solvable ($N = 1$), we added a ninth clue that disambiguates the remaining possibilities without naming any friend:

- **Chosen Solution to Keep**: Solution 2
- **English Clue**: *"The friend whose favorite language is Java prefers embedded projects."*
- **Prolog Implementation**:
  ```prolog
  % CLUE 9: The friend whose favorite language is Java prefers embedded projects.
  clue(9, S) :-
      member(p(_, _, java, embedded), S).
  ```

### Verification
- In **Solution 2**, the friend whose favorite language is Java works on `embedded` (**True**).
- In **Solution 1** and **Solution 3**, the friend whose favorite language is Java works on `'AI'` (**False**).
- Running `count_solutions([1, 2, 3, 4, 5, 6, 7, 8, 9], N)` produces:
  $$\mathbf{N = 1}$$
The puzzle is now fully constrained and possesses a unique valid solution.
